# Lesson4.3 - Симуляция зоопарка

## 📌 Описание
Этот проект моделирует **зоопарк** с животными и сотрудниками. Можно добавлять новых животных, сотрудников, кормить и лечить животных, а также сохранять и загружать состояние зоопарка.

## 🚀 Установка и запуск

### 1. Убедитесь, что у вас установлен Python
Проверьте версию Python:
```sh
python --version
```
Проект протестирован на **Python 3.8+**.

### 2. Клонируйте репозиторий
```sh
git clone https://github.com/Alexandr-sys2024/Lesson4.3.git
cd Lesson4.3
```

### 3. Запуск симуляции зоопарка
```sh
python main.py
```

## 📂 Основные файлы
- **`main.py`** – основной код симуляции зоопарка.
- **`zoo_data.pkl`** – сериализованные данные о животных.
- **`zoo_state.pkl`** – текущее состояние зоопарка.

## 🎮 Функции зоопарка
✅ Добавление новых животных и сотрудников.  
✅ Кормление и лечение животных.  
✅ Сохранение и загрузка данных зоопарка.  
✅ Поддержка различных классов животных и сотрудников.
